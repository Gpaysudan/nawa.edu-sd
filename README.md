# نَوّى | Nawa Tech & Skills

واجهة تدريبية ثنائية اللغة تعمل كلياً في المتصفح، بلا خادم أو قاعدة بيانات. التسجيل يجهّز رسالة ويحوّلها إلى WhatsApp، والأسئلة الشائعة مبرمجة محلياً في JavaScript.

## التشغيل المحلي

افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. استخدام خادم محلي مهم لاختبار تثبيت PWA وService Worker؛ فتح `index.html` مباشرة عبر `file://` لا يتيح هذه الميزات للمتصفح.

## النشر على GitHub Pages

ارفع محتويات مجلد المشروع إلى مستودع GitHub. من **Settings → Pages** اختر الفرع المطلوب ومجلد الجذر `/`، ثم احفظ. جميع مراجع CSS وJavaScript والأيقونات والـ manifest والـ Service Worker نسبية، لتعمل أيضاً عند نشر الموقع تحت مسار مستودع مثل `https://username.github.io/repository/`.

إذا كان النشر من مجلد فرعي، ارفع محتويات المشروع إلى ذلك المجلد أو اضبط مصدر Pages عليه. لا يحتاج الموقع إلى متغيرات بيئة أو إعداد Backend. Google Fonts وFont Awesome يحتاجان اتصالاً بالشبكة؛ المحتوى والتصفية والتسجيل المحلي والأسئلة الشائعة تعمل دون اتصال بعد أول زيارة. لكل أكاديمية رسم SVG محلي بديل، وللمطور أفاتار محلي بالنظارة؛ لذلك تبقى صور المسارات ظاهرة على GitHub Pages وعند غياب صور الاستضافة المُدارة. نموذج المشروع في قسم المطور يجهّز رسالة WhatsApp ولا يحفظ بياناته أو يرسلها إلا عند اختيار المستخدم.

## الملفات الرئيسية

- `index.html`: هيكل الصفحة والعناصر التفاعلية.
- `styles.css`: الهوية البصرية والتجاوب والوضعان الليلي والنهاري.
- `app.js`: اللغتان، كتالوج المسارات وصوره وأيقوناته، التسجيل، نموذج طلب المشروع، والأسئلة الشائعة التفاعلية.
- `manifest.webmanifest` و`sw.js`: تثبيت PWA والعمل دون اتصال.
- `assets/`: الشعار والرسوم والأيقونات.
